# Mandar o link automático quando alguém comentar "EU QUERO" (Instagram)

Ferramenta: **ManyChat** (manychat.com) — parceira oficial da Meta, tem plano grátis.

## 1. Antes de tudo (no app do Instagram)
- Perfil precisa ser **Profissional** (Criador de conteúdo ou Empresa): Configurações → Tipo de conta e ferramentas → Mudar para conta profissional.
- Configurações → Mensagens e respostas aos stories → Controles de mensagens → **Ferramentas conectadas → Permitir acesso às mensagens** (ligado).

## 2. Criar a conta no ManyChat
1. Entre em manychat.com → **Get Started Free** → escolha **Instagram**.
2. Faça login com o Instagram e aceite as permissões.

## 3. Criar a automação
1. Menu **Automation** → **+ New Automation** → **Start from Template** → escolha **"Auto-DM links from comments"**
   (ou crie do zero com o gatilho **"User comments on your Post or Reel"**).
2. Gatilho:
   - **Qual post:** "Specific Post or Reel" → escolha o Reels do tênis (ou "Any Post or Reel" para valer em todos).
   - **Palavras-chave:** `EU QUERO`, `eu quero`, `Eu quero`, `euquero`, `quero` (marque "contains" / "contém").
   - Ative **"Reply to their comment publicly"** com respostas variadas, por exemplo:
     - `Te mandei no direct! 📩`
     - `Enviado! Confere sua DM 😉`
     - `Já tá no seu direct! 🐯`
3. Mensagem no Direct (DM):
   ```
   Opa! Aqui está o link do tênis Fila 👟🐯

   🔗 https://meli.la/2xCt7on

   Ou cole este código no buscador do Mercado Livre: 2JUBS1-CKKG
   ```
   Dica: use o bloco **"Button"** com o texto **"VER O TÊNIS"** apontando para o link — botão é clicado muito mais que link solto.
4. Clique em **Set Live** (ativar).

## 4. Testar
Peça para um amigo comentar "eu quero" no Reels (o seu próprio comentário não dispara).

## Observações
- Plano grátis do ManyChat: até ~1.000 contatos; depois disso é pago.
- Para cada vídeo novo, crie uma automação nova (ou edite o link da existente).
- Alternativas parecidas: LinkDM, Inrō.
